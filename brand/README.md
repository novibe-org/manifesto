# Brand

Every icon is a black hexagon with a code token in its product's colour.

| | Token | Colour |
|---|---|---|
| NoVibe | `!~` — "does not match": no vibe | yellow |
| cockpit | `=>` — the result | mint |
| agentbox | `>_` — the prompt you SSH into | blue |
| plugin | `/` — the slash command | pink |

- `icons/dark/` — the icons in use; `public/icons/` serves the same files on the site.
- `icons/color/` — the alternative: a colour hexagon with a white token.
- `github/` — the organisation avatar and each repository's social preview, uploaded by hand in GitHub's settings.
- `exploration/` — the 50 variants, the finalists and the final set they were chosen from.
